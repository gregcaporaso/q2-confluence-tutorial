# q2-confluence tutorial

**README** · [Installation](install.md) · [Tutorial](tutorial.md) · [Data preparation](data-preparation.md)

<img src="assets/musee-des-confluences.jpg" align="right" width="33%" alt="View through the steel and glass frame of the Musée des Confluences, Lyon, France, over the river below">

⚠️ This tutorial and the [rachis](https://rachis.org) [plugins](https://news.rachis.org/en/latest/glossary/#term-plugin) it uses are in early testing (alpha release) phase.
Commands will almost certainly change.
Be skeptical of results - testing is still in progress.

The tutorial integrates 16S rRNA amplicon and metagenome profiles of the same [samples](https://news.rachis.org/en/latest/glossary/#term-sample) in the [feature](https://news.rachis.org/en/latest/glossary/#term-feature) space of one GTDB release's genomes, with the [q2-confluence](https://github.com/gregcaporaso/q2-confluence) and [mosh-sylph](https://github.com/gregcaporaso/mosh-sylph) plugins for [QIIME 2](https://news.rachis.org/en/latest/glossary/#term-qiime-2).

Start by [installing](install.md).
Then work through [the tutorial](tutorial.md).
A separate page describes [how the tutorial data were prepared](data-preparation.md) with QIIME 2 [(Bolyen *et al.* (2019))](https://doi.org/10.1038/s41587-019-0209-9) (for amplicon data) and MOSHPIT [(Ziemski *et al.* (2026))](https://doi.org/10.1016/j.xgen.2026.101366) (for metagenome data).

The tutorial is published at [gregcaporaso.github.io/q2-confluence-tutorial](https://gregcaporaso.github.io/q2-confluence-tutorial/), and its source is at [github.com/gregcaporaso/q2-confluence-tutorial](https://github.com/gregcaporaso/q2-confluence-tutorial).

Questions and bug reports should be directed to the [QIIME 2 Forum](https://forum.qiime2.org).
